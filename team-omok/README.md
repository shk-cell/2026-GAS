# 팀 오목 (Google Apps Script)

레드 팀과 블루 팀이 번갈아 두는 실시간 오목입니다. 같은 팀 안에서는 들어온 순서대로 한 명씩 돌아가며 둡니다.

## 만들기
1. script.google.com → 새 프로젝트
2. `Code.gs` 내용을 모두 지우고 이 폴더의 `Code.gs`를 붙여넣기
3. 파일 추가(+) → HTML → 이름 `index` → 이 폴더의 `index.html`을 붙여넣기
4. 배포 → 새 배포 → 유형: 웹 앱
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한: **모든 사용자** (학교 계정이면 도메인 내 모든 사용자)
5. 웹 앱 주소를 학생들에게 공유 (QR로 만들면 편해요)

스프레드시트는 필요 없습니다. 게임 상태는 CacheService에 6시간 동안 저장됩니다.

## 규칙
- 처음 들어온 사람이 방장(👑)입니다. 방장이 나가면 다음 사람이 이어받습니다.
- 레드와 블루에 한 명 이상씩 있으면 방장이 시작할 수 있습니다.
- 다섯 개 이상 이으면 승리합니다.
- 삼삼(3-3) 금지: 한 수로 열린 3을 두 개 동시에 만드는 자리는 둘 수 없습니다(두 팀 모두). 판에 ×로 표시되며, 그 수로 바로 다섯이 되면 둘 수 있습니다. 끄려면 `Code.gs`의 `BAN_33`을 `false`로 바꾸세요.
- 20초 동안 접속이 없으면 '자리 비움'으로 표시되고, 차례가 오면 건너뜁니다.
- 게임 중에 들어온 사람은 팀을 고르면 그 팀 순서의 맨 뒤에 붙습니다.

## 알아 둘 점
- 배포 하나가 방 하나입니다. 여러 반이 따로 하려면 각자 배포하세요.
- 각자 1.5초마다 서버에 물어보는 방식이라, 돌이 보이기까지 1~2초 걸릴 수 있습니다. 한 반(30명 안팎)을 기준으로 만들었으니 수업 전에 미리 시험해 보세요. 느리면 `index.html`의 `POLL_MS`를 2000~3000으로 늘리세요.
- 방을 처음 상태로 비우려면 편집기에서 `resetRoom` 함수를 실행하세요.
- 한 브라우저는 한 사람으로 인식됩니다. 혼자 여러 명을 시험하려면 시크릿 창이나 다른 브라우저를 쓰세요.
