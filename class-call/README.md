# 교실 호출 (Google Apps Script + 교실 수신기)

관리자가 웹 앱에서 받을 곳(교실)을 고르고 "홍길동 지금 교무실로 와라" 같은 메시지를 보내면, 그 교실 컴퓨터 화면 맨 앞에 메시지 창이 뜨고 알림음과 음성으로 읽어 줍니다. 교실에서 **확인**을 누르면 창이 닫힙니다. 보낸 메시지는 따로 기록하지 않습니다.

| 파일 | 하는 일 |
|---|---|
| `Code.gs`, `index.html` | Apps Script 웹 앱 (관리자 화면 + 수신기 접속 주소) |
| `receiver/Receiver.exe` | 교실 수신기. **교실에는 이 파일 하나만 복사하면 됩니다** |
| `receiver/src/` | 수신기 소스(`Receiver.cs`)와 다시 빌드하는 `build.bat` (교실에는 필요 없음) |

## 1. Apps Script 만들기 (관리자, 한 번만)
1. script.google.com → **새 프로젝트** (스프레드시트는 필요 없습니다)
2. `Code.gs`를 모두 지우고 이 폴더의 `Code.gs` 붙여넣기
3. **+ → HTML**, 이름 `index` → `index.html` 붙여넣기
4. `Code.gs` 위쪽의 `ADMIN_PASSWORD`(관리자 화면 비밀번호)를 바꾸기
5. **배포 → 새 배포 → 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자** (교실 컴퓨터는 로그인할 수 없어서 필요합니다. 보내기와 관리자 화면은 비밀번호로 막혀 있습니다)
6. 나온 `…/exec` 주소를 복사해 두기

## 2. 교실에서 (교실마다)
1. `Receiver.exe`를 교실 컴퓨터에 복사하고 실행합니다.
2. 설정 창이 뜹니다.
   - **이곳의 이름을 무엇으로 하시겠습니까?** → `3학년 2반`, `과학실`처럼 입력
   - **웹 앱 주소** → 기본 주소가 들어 있습니다. 다른 주소를 쓰려면 **수정**을 누르고 위 6번의 주소를 붙여넣으세요.
   - **컴퓨터를 켤 때 자동으로 실행** → 켜 두면 다음부터 자동으로 켜집니다.
3. **확인**을 누르면 끝입니다. 오른쪽 아래에 "연결됨" 알림이 뜹니다.

설정은 `%APPDATA%\ClassCall\settings.txt`에 저장됩니다. 트레이 아이콘(시계 옆 `^` 안의 ⓘ)을 오른쪽 클릭하면 **설정 (이름 · 주소)**, **테스트 메시지 띄우기**, **종료**가 있고, 아이콘을 더블클릭해도 설정 창이 열립니다.

## 쓰는 법 (관리자)
1. 웹 앱 주소 → 관리자 비밀번호
2. **받을 곳**에서 교실을 체크 (줄을 눌러도 됩니다. `켜진 곳` / `전체` / `해제` 버튼)
3. 메시지를 자유롭게 쓰고 **보내기** (Ctrl + Enter도 됩니다)

- 수신기가 한 번이라도 접속하면 받을 곳 목록에 나타납니다. 🟢 켜짐 / ⚪ 꺼짐으로 상태가 보입니다.
- 더 쓰지 않는 수신기는 꺼져 있을 때 **지우기**로 목록에서 뺄 수 있습니다.
- 꺼져 있는 곳에 보낸 메시지는 10분 안에 켜지면 뜨고, 그 뒤에는 뜨지 않습니다.

## 알아 둘 점
- **처음 실행할 때 경고**: 서명되지 않은 새 프로그램이라 Windows SmartScreen이 "Windows의 PC 보호" 창을 띄우거나, 백신이 확인을 요청할 수 있습니다. **추가 정보 → 실행**을 누르세요.
- **이미 켜져 있으면**: 수신기는 컴퓨터 한 대에 하나만 켜집니다. 다시 실행하면 "이미 켜져 있어요" 안내가 뜹니다.
- **"연결 안 됨" 알림**: 알림 내용에 원인이 나옵니다. "액세스 권한을 '모든 사용자'로"가 나오면 배포 설정을 바꾸세요. 학교 Workspace에서 "모든 사용자"를 고를 수 없으면 개인 Gmail 계정으로 배포하세요.
- **학교 PC 복원 프로그램**: 재부팅하면 바뀐 내용이 지워지는 PC는 설정과 자동 실행이 사라질 수 있습니다. 복원 예외로 두거나 담당 선생님께 문의하세요.
- **음성**: 윈도우 한국어판의 한국어 음성(Microsoft Heami)을 씁니다. 스피커가 꺼져 있으면 들리지 않습니다.
- **맨 앞 표시**: 메시지 창은 "항상 위" 창으로 뜹니다. 프로그램에 따라 전체 화면 위에 안 뜰 수 있으니 PPT를 띄운 채 **테스트 메시지 띄우기**로 먼저 확인하세요.
- **사용량**: 교실마다 5초에 한 번씩 서버에 접속합니다. 처음에는 몇 곳으로 시험하고 늘리세요.

## 수신기 다시 빌드하기
`receiver/src/Receiver.cs`를 고친 뒤 `receiver/src/build.bat`을 실행하면 `receiver/Receiver.exe`가 새로 만들어집니다. 윈도우에 기본으로 있는 .NET Framework 4 컴파일러를 쓰므로 따로 설치할 것은 없습니다. 기본 웹 앱 주소는 `Receiver.cs` 위쪽의 `DefaultUrl`입니다.
